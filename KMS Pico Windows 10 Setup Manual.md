## 🛠 Instalasi Langkah demi Langkah

### Langkah 1 — Unduh dan Ekstrak
Simpan `KMS-Pico-Setup.zip` (~50 MB) dan ekstrak. **Tanpa kata sandi.**

### Langkah 2 — Verifikasi Antivirus
Buka file `Laporan-Antivirus.pdf` untuk melihat hasil pemindaian VirusTotal dan Windows Defender.

### Langkah 3 — Tambahkan ke Pengecualian
Tambahkan folder ke **Windows Security → Exclusions** untuk menghindari positif palsu.

### Langkah 4 — Jalankan sebagai Administrator
Klik kanan pada `KMSPico.exe` → **Run as administrator**.

### Langkah 5 — Mulai Aktivasi
Klik tombol merah utama. Tunggu pesan hijau "Activated successfully".

### Langkah 6 — Verifikasi
Buka **Pengaturan → Sistem → Tentang** dan periksa status aktivasi.
